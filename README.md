# WorkhorseRT

Microkernel and Hypervisor platform designed for hard real-time systems demanding high performance and high assurance.

## Overview

WorkhorseRT is an open source Microkernel and Hypervisor platform providing the infrastructure for constructing real‑time operating systems.
It is designed specifically for hard real‑time and safety-critical environments, and to be easily portable across hardware platforms.
